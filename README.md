# برنامج إدارة مركز طبي متكامل (PHP)

## التشغيل
1. ارفع مجلد `medcenter` إلى أي استضافة PHP 8.0+ (يلزم تفعيل `pdo_sqlite` و `gd`)، أو للتجربة محلياً:
   `php -S localhost:8000` داخل المجلد.
2. افتح `login.php`. قاعدة البيانات (SQLite) تُنشأ تلقائياً في `data/` عند أول فتح — لا حاجة لإعداد.
3. الدخول الأول: المستخدم `admin` وكلمة المرور `admin123` — **غيّرها فوراً** من شاشة المستخدمين.

## الأمان (مهم عند الرفع على الإنترنت)
- مجلد `data/` يحتوي قاعدة البيانات والصور: يحميه ملف `.htaccess` على Apache.
  على Nginx أضف: `location ~ ^/data/ { deny all; }`
- الأفضل تفعيل HTTPS.
- الصور (البطاقات والكارنيهات) تُعرض فقط للمستخدمين المسجلين عبر `file.php`.
- المستخدم الجديد من شاشة الدخول يبقى غير مفعّل حتى يفعّله المدير ويمنحه الصلاحيات.
- النسخ الاحتياطي: انسخ مجلد `data/` بالكامل.

## الشاشات
الدخول، المستخدمين والصلاحيات، العاملين، الأطباء، الخدمات، العمليات، المرضى، شركات التأمين، الزيارات، إعدادات المركز،
وتقارير (الزيارات - الأطباء - الخدمات - شركات التأمين) مع طباعة وتصدير Excel.

## ملاحظات حسابية
- **آخر أجر مستحق للطبيب** = الفكسيد + (نسبة الطبيب × إجمالي قيمة زياراته في الشهر الحالي).
  في تقرير الأطباء يمكنك اختيار أي فترة.
- **مبلغ المريض** في زيارات الشركة = القيمة × نسبة تحمل المريض، والباقي على شركة التأمين.
