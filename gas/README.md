# تركيب الخادم على Google Apps Script (نسخة مستقلة بدون GitHub)

1. افتح المشروع في script.google.com.
2. **احذف أي ملفات .gs أخرى** (مثل المحمّل القديم) واترك ملفاً واحداً اسمه `Code.gs` والصق فيه محتوى `Code.gs` كاملاً.
3. أنشئ ملف HTML باسم `Index` (بدون .html) والصق فيه `Index.html`.
4. من إعدادات المشروع فعّل «إظهار ملف appsscript.json» والصق محتوى `appsscript.json`.
5. شغّل الدالة `setup` مرة واحدة ووافق على الصلاحيات.
6. نشر ← نشر جديد ← تطبيق ويب (تنفيذ كـ: أنا، الوصول: أي شخص). للتحديث لاحقاً: إدارة عمليات النشر ← ✏ ← إصدار جديد (يبقى الرابط).
