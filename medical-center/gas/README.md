# نسخة Google Script — برنامج إدارة المركز الطبي
البيانات في Google Sheets (أوراق مقروءة بأسماء الشاشات تتحدث تلقائياً)، والصور في مجلد خاص على Google Drive.

## الخطوات (ملفان فقط)
1. افتح https://script.google.com → **مشروع جديد**، واحذف أي ملفات قديمة بداخله.
2. ملف `Code.gs`: امسح محتواه كله والصق محتوى `Code.gs` الجديد (يتضمن البيانات الأساسية، لا حاجة لـ Seed.gs).
3. ملف `Index.html` (من «+» ← HTML، الاسم Index بالضبط): الصق محتوى `Index.html` كله.
4. (اختياري) ⚙ إعدادات المشروع ← «إظهار ملف appsscript.json» والصق `appsscript.json`.
5. اختر الدالة **setup** من القائمة العلوية واضغط **تشغيل** ووافق على الأذونات؛ تُنشأ ملفات الأوراق.
6. **نشر ← عملية نشر جديدة ← تطبيق ويب**: التنفيذ باسم «أنا»، والوصول «أي شخص».
7. افتح الرابط ← **إنشاء أول مستخدم** (يصبح المدير).
8. عند أي تعديل: **نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد ← نشر**.

لا يوجد رابط إضافي مطلوب: ضع رابط `/exec` في `server.json` في المستودع ليستخدمه الأندرويد وبقية النسخ.
