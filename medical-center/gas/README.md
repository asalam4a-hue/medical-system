# نسخة Google Script — برنامج إدارة المركز الطبي (تحديث تلقائي)
البيانات في Google Sheets، والصور في مجلد خاص على Google Drive.

## التثبيت (مرة واحدة فقط)
1. https://script.google.com → **مشروع جديد**، واحذف أي ملفات قديمة.
2. ملف `Code.gs`: امسح محتواه والصق محتوى `Code.gs` (محمّل صغير لا يتغير بعد ذلك).
3. ⚙ إعدادات المشروع ← «إظهار ملف appsscript.json» والصق محتوى `appsscript.json` (يضيف إذن الاتصال بـ GitHub).
4. اختر الدالة **setup** ← **تشغيل** ووافق على الأذونات.
5. **نشر ← عملية نشر جديدة ← تطبيق ويب**: التنفيذ باسم «أنا»، والوصول «أي شخص». انسخ رابط `/exec`.
6. ضع الرابط في `server.json` بالمستودع (أو من زر «🔗 تغيير رابط الخادم» في البرنامج على كل جهاز).

## بعد ذلك
كود الخادم (`core.js`) والواجهة (`Index.html`) يُحمَّلان تلقائياً من GitHub (`medical-center/gas`) ويتجددان خلال دقائق من أي تعديل — **بدون نشر جديد وبدون تغيير الرابط**.
نسخة PHP والأندرويد تتحدثان تلقائياً من `medical-center/php/index.html` كذلك.
